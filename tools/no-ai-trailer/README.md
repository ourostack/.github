# no-ai-trailer

Stops an AI or bot co-author credit from reaching a default branch. `check.sh` is the sweep and the PR check (`no-ai-trailer-pr.yml`); a ruleset rejects the merge itself.

**Merge-time rule.** The `no-ai-credit-trailer` ruleset (commit message must not match `(?i)co-authored-by:[^\n]*(\[bot\]|copilot)`, default branch, no bypass) is on every unarchived, non-fork ourostack repository as a repository ruleset (ids from 27437249, e.g. `.github` is 27437273; reapply with `apply-repo-rulesets.sh`). Creating the single org ruleset needs `admin:org` or the web UI, and both ask for GitHub sudo mode (a passkey or GitHub Mobile tap), so run `node tools/no-ai-trailer/batch-sudo-steps.mjs`: one approval (a GitHub Mobile tap, number sent to Teams, or a passkey in a visible Edge window) creates the org ruleset, removes the per-repo copies with `apply-repo-rulesets.sh --remove`, and deletes `ourostack/zz-trailer-proof`. Proof (2026-11-16, throwaway repo `ourostack/zz-trailer-proof`, ruleset 27436928): squash merges whose message carried `Co-authored-by: copilot-swe-agent[bot]`, `Co-authored-by: Copilot` or a human line followed by `dependabot[bot]` were rejected with a 409; a clean message and human-only co-authors merged; `gh ouro-pr merge` on a PR whose commits and body carried the credit landed clean with auto-merge. GitHub's regex treats `^` as the start of the whole message, not of a line, so the pattern has no anchor; the first draft (`^[ \t]*co-authored-by...`) let a trailer in the body through. A default web merge of a branch whose commits carry a trailer is blocked: merge with `gh ouro-pr merge <pr>`.
